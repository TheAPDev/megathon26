1Current approach and changes since M1

The approach is unchanged in shape: score = fixed-weight sum of seven explainable sub-scores (energy efficiency 25%, consumption intensity 20%, envelope 15%, cooling system 15%, windows and shading 10%, renewables 10%, smart use 5%), bands 80/65/50/30. Estimates come from a physics model × LightGBM residual, retrofits are applied sequentially so savings never double count, a LambdaRank ranker orders them, and a hedonic value model with conformal intervals prices the uplift. An LLM only narrates numbers the engine returns, and a verifier checks every figure. What M1 described as a plan is now built and running end to end:

Decisions changed since M1: (1) we calibrate against real public data instead of trusting the generator; (2) the LLM provider moved from Llama 3.3 to Nemotron, and because hosted models cannot be fine-tuned through the API we adapt it with prompt, few-shot and an SFT dataset instead; (3) login moved from email code to username and password.
